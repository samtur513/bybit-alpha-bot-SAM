# Полное руководство по развёртыванию: Bybit Multi-Alpha Bot v2.0

> Квантовая мульти-активная торговая система для бессрочных фьючерсов Bybit Linear Perpetuals (USDT).
> 18 инструментов, 120-часовой пробой Дончяна, сайзинг Half-Kelly (2.5%), антимартингейл (+50% на +2 ATR) и встроенный веб-дашборд на порту 8080.

## 2. Системные требования к серверу (VPS)

* **ОС**: Ubuntu 20.04 LTS / 22.04 LTS / 24.04 LTS (или Debian 11/12).
* **Процессор**: от 1 vCPU.
* **Оперативная память**: от 1 GB RAM.
* **Дисковое пространство**: от 5 GB SSD.
* **Сетевой доступ**: открытый исходящий доступ в интернет (к `api.bybit.com`) и входящий TCP-порт `8080` для просмотра веб-дашборда.

## 3. Быстрая установка на чистый сервер (за 1 минуту)

### Вариант А: Развёртывание из архива `tar.gz`

1. Загрузите архив на сервер (через SCP/SFTP или `wget`/`curl`):
   ```bash
   scp bybit_alpha_bot_v2.tar.gz root@ВАШ_IP:/opt/
   ```

2. Подключитесь по SSH и распакуйте:
   ```bash
   mkdir -p /opt/bybit-bot
   tar -xzf /opt/bybit_alpha_bot_v2.tar.gz -C /opt/bybit-bot
   cd /opt/bybit-bot
   ```

3. Запустите автоматический установщик:
   ```bash
   bash setup.sh
   ```

Скрипт автоматически:
* Установит `python3-venv` и зависимости (`pandas`, `requests`).
* Настроит изолированное окружение `venv`.
* Зарегистрирует и включит фоновую службу `bybit-bot.service` в `systemd` (автозапуск при ребутах).
* Откроет порт `8080` в фаерволе `ufw`.
* Запустит бота и выдаст готовую ссылку на веб-дашборд.

---

## 4. Как запустить новый чистый тест ($300.00)

Если вы хотите начать тест с нуля с чистого листа:

```bash
cd /opt/bybit-bot
bash reset_test.sh
```

Этот скрипт:
1. Останавливает службу.
2. Обнуляет историю сделок и открытые позиции.
3. Устанавливает начальный баланс ровно в **$300.00 USDT**.
4. Запускает службу заново.

## 5. Мониторинг и управление

### В браузере:
* **Веб-дашборд**: `http://ВАШ_IP_СЕРВЕРА:8080`
* **Снапшот статуса в JSON**: `http://ВАШ_IP_СЕРВЕРА:8080/api/status`
* **Сохранённое дисковое состояние**: `http://ВАШ_IP_СЕРВЕРА:8080/api/state`
* **Логи бота прямо в браузере**: `http://ВАШ_IP_СЕРВЕРА:8080/api/logs`

### В консоли сервера:
* Посмотреть статус: `bash status.sh` *(или `systemctl status bybit-bot`)*
* Живые логи бота: `bash logs.sh` *(или `journalctl -u bybit-bot -f`)*
* Перезапустить: `bash restart.sh` *(или `systemctl restart bybit-bot`)*
* Остановить: `bash stop.sh` *(или `systemctl stop bybit-bot`)*

## 7. Переход на реальную торговлю (Live Trading)

По умолчанию бот работает в безопасном режиме высокоточного **Paper Trading** (ордера симулируются по реальным тикам и свечам Bybit V5 с учётом полных комиссий Taker 0.06% и проскальзывания 0.02%).

Для переключения на исполнение реальных ордеров через API Bybit:
1. Создайте API-ключи на Bybit (права: *Contract Trading* / *Read-Write*).
2. Создайте файл `.env` в корневой папке бота:
   ```bash
   nano /opt/bybit-bot/.env
   ```
3. Добавьте ваши ключи:
   ```env
   BYBIT_API_KEY=ваш_api_ключ
   BYBIT_API_SECRET=ваш_секретный_ключ
   BYBIT_TESTNET=false
   TRADING_MODE=LIVE
   ```
4. Перезапустите службу: `bash restart.sh`.
