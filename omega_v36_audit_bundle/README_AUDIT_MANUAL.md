## 1. Концепция и архитектурный манифест

Движок **v3.6 Omega Dual-Regime ZF-8** решает главную фундаментальную проблему направленных трендовых систем в криптовалюте: **убыточный износ капитала (frictional drawdown) в затяжных боковиках (chop/range)** при сохранении экспоненциального набора прибыли на взрывных импульсах.

Система объединяет три независимых квантовых модуля в единый монолит:
1. **Трендовый модуль ZF-8**: 8-ступенчатая адаптивная трансмиссия моментума с нелинейным кикдауном (разгон до 3.6% риска и пирамидинг до +100%) и мгновенным торможением ABS (сброс -2 передач на стопе).
2. **Флэтовый модуль IRAS Range Maker**: Автоматический сбор мейкер-спреда на границах полос Боллинджера в стационарном шуме (KER $\le 0.15$) с тейком на SMA20 и комиссией мейкера 0.0324%.
3. **Защитный щит News Core v1.2**: Календарное макро-эмбарго ([-45 мин, +30 мин] вокруг CPI, FOMC, NFP) и аварийный сброс позиций при рыночных шоках.

## 2. Математические формулы и алгоритмы

### 2.1. Строгий учет средней цены пирамидинга (Invariant #1)
Никакой расчёт прибыли по добору позиции не ведётся от цены первого входа. Используется строгая взвешенная средняя цена объема (**VWAP**):
$$P_{\text{entry}}^{\text{new}} = \frac{P_{\text{old}} \cdot Q_{\text{old}} + P_{\text{add}} \cdot Q_{\text{add}}}{Q_{\text{old}} + Q_{\text{add}}}$$

При закрытии позиции выполняется абсолютная консервация капитала:
$$\text{Net PnL} = (P_{\text{exit}} - P_{\text{entry}}^{\text{new}}) \cdot Q_{\text{total}} \cdot \text{Direction} - \sum \text{Fees} - \sum \text{Slippage}$$
$$\text{Realized Equity}_{t} = \text{Realized Equity}_{0} + \sum_{i=1}^{N} \text{Net PnL}_i$$

### 2.2. Коэффициент эффективности Кауфмана (KER 14)
Используется для математического отделения направленного дрейфа от стационарного белого шума:
$$\text{KER} = \frac{|P_t - P_{t-14}|}{\sum_{i=0}^{13} |P_{t-i} - P_{t-i-1}|}$$
* $\text{KER} \le 0.15$: **Стационарный шум (Chop)**. Направленный тренд отсутствует. Разрешен запуск IRAS Range Maker.
* $\text{KER} > 0.15$: **Направленное движение**. Режим Range строго блокируется во избежание ловли падающих ножей против тренда.

### 2.3. Спецификация 8-ступенчатой коробки передач ZF-8

| Ступень | Режим (Tag) | Базовый риск | Тейк TP1 (R) | Тейк TP2 (R) | Добор (Пирамидинг) | Целевой R:R |
| :---: | :---: | :---: | :---: | :---: | :---: | :---: |
| **G1** | LIMP / CRAWL | **1.0%** | +2.8R | +3.6R | **Запрещен (0%)** | 1:2.8 — 1:3.6 |

#### Динамика переключения передач:
1. **Smart Kickdown (Разгон на раннерах)**:
   * Мега-раннер ($R \ge +5.0\text{R}$): переключение **+3 передачи** вверх (например, G3 $\rightarrow$ G6).
   * Супер-раннер ($+3.2\text{R} \le R < +5.0\text{R}$): переключение **+2 передачи** вверх (G2 $\rightarrow$ G4).
   * Обычная победа ($+0.3\text{R} \le R < +3.2\text{R}$): переключение **+1 передача**.
2. **ABS Rapid Braking (Экстренное торможение)**:
   * Полный стоп-лосс ($R < -0.7\text{R}$): мгновенный сброс **-2 передач** вниз (G6 $\rightarrow$ G4, G3 $\rightarrow$ G1).
   * Мягкий убыток / скретч ($-0.7\text{R} \le R \le -0.3\text{R}$): сброс **-1 передача**.
   * Безубыток ($|R| < 0.3\text{R}$): нейтраль (передача сохраняется).
3. **Limp Mode (Аварийный предохранитель)**:
   * При достижении локальной просадки **$\ge 8.0\%$** коробка принудительно блокируется в **1-й передаче (G1, 1.0% риск)**.
   * Восстановление рабочих передач разрешено только после снижения просадки до **$\le 4.0\%$**.

### 2.4. IRAS Range Maker (Логика отскока от границ)
* **Индикаторы**: Полосы Боллинджера (20, 2.0), Keltner Channels (20, 1.5 ATR).
* **Фильтр ширины канала (Bandwidth Clearance)**:
  $$\text{Bandwidth} = \frac{\text{BB}_{\text{upper}} - \text{BB}_{\text{lower}}}{\text{BB}_{\text{mid}}} \ge 3.0\%$$
* **Исполнение**: Лимитные ордера `LIMIT_MAKER` на касании внешней полосы.
* **Выход по цели**: Лимитный тейк ровно на средней линии SMA20 (сбор мейкер-спреда).
* **Защитный стоп**: $1.0 \times \text{ATR}$ за внешней полосой.

### 2.5. News Core v1.2 (Защитный комплекс)
* **Календарное макро-эмбарго**: Окно $[-45\text{ мин} : +30\text{ мин}]$ вокруг запланированных релизов FOMC Rate Decision, CPI, NFP, Core PCE. В этом окне любые новые входы блокируются.
* **Pre-Macro Profit Trimming**: За 45 минут до макро-события открытые прибыльные позиции с плавающим профитом $\ge 1.0\text{R}$ фиксируют $30\%$ объема, защищая накопленную прибыль от вертолётов.

## 4. Инструкция по запуску и проверке

### 4.1. Установка зависимостей
```bash
python -m venv venv
source venv/bin/activate  # (на Windows: venv\Scripts\activate)
pip install -r requirements.txt
```

### 4.2. Запуск проверочной тестовой сюиты
Для проверки математических инвариантов и логики переключения передач запустите:
```bash
pytest tests/ -v
```
Все тесты должны завершиться со статусом **`100% PASSED`**.

### 4.3. Запуск веб-дашборда и демона
```bash
python web_dashboard.py
```
Сервер запустится на порту `8089` (http://localhost:8089) с отображением живой АКПП, радара активов и стакана позиций.

## 5. Вопросы для независимого квантового аудитора

При проведении независимой экспертизы рекомендуется обратить внимание на следующие аспекты:

1. **Моделирование проскальзывания лимитных мейкеров**: В бэктесте заложено, что 100% лимитных ордеров IRAS на отскок от Боллинджера исполняются по цене границы. Насколько консервативен этот подход в условиях высокой волатильности азиатской сессии?
2. **Калибровка порога KER**: Текущий оптимум отсечки стационарного флэта установлен на уровне $KER \le 0.15$. Изучите, даёт ли адаптивный порог $KER \le \text{Percentile}_{20}(KER)$ дополнительное преимущество перед статическим 0.15.
3. **Алгоритм выхода из Limp Mode**: Предохранитель активируется при $DD \ge 8.0\%$ и отпускает коробку при $DD \le 4.0\%$. Рекомендуется оценить влияние гистерезисного буфера (например, требование 5 безубыточных баров в дополнение к возврату просадки).
4. **Взаимная корреляция пар при пирамидинге**: При переходе на передачи G6–G8 суммарное плечо может достигать 3.5x. Проверьте поведение портфеля в сценарии flash crash по Bitcoin при одновременном открытии 3 альткоинов.
