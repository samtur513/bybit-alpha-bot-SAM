# Multi-Alpha Growth Engine v2.1 (A/B Test Branch & Audited Core)

## 📌 Обзор и архитектура v2.1

Версия **v2.1** объединяет в себе:
1. **Институциональный аудит ядра (ChatGPT Quantitative Audit)**:
   - **Честный средневзвешенный расчет цены входа при пирамидинге** (устранена иллюзия фантомного PnL при доливках).
   - **Денежный безубыток (Basket Cash Breakeven)**: стоп-лосс после доливки рассчитывается с учётом комиссий входа, доливки, funding и slippage всей корзины.
   - **Защита от ложных срабатываний стопа**: отказ от использования старых экстремумов (`pos.lowest_price`), переход на строгую тиковую последовательность.
   - **Лимит совокупного плеча**: проверка gross-экспозиции (3.5x cap) перед каждой доливкой.
   - **Аппаратный Circuit Breaker**: автоматическая заморозка торговли (`trading_halted`) при достижении просадки 18%.
   - **Public WebSocket Stream**: переход на официальный WebSocket Bybit V5 (`tickers.*`, `kline.60.*`) вместо 5-секундного REST-поллинга.
   - **Пагинация инструментов Bybit**: получение всех >450 контрактов через `nextPageCursor`.
   - **Безопасность**: публичные эндпоинты мутации портфеля заблокированы (403 Forbidden).
   - **Telegram-уведомления**: опциональная отправка сигналов и ежедневных отчетов в ваш личный чат.

2. **Собственные усовершенствования v2.1**:
   - **BTC Delta Trend Filter**: Long по альтам открывается только при подтверждении бычьего тренда BTC.
   - **3-Bar Re-entry Cooldown**: 3 часа ожидания перед повторным входом в ту же монету после закрытия позиции.
   - **Комиссия Bybit с учетом MNT**: тейкер `0.09%` (`BASE_TAKER_FEE = 0.0009`).
