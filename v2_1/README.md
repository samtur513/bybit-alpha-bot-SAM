# Multi-Alpha Growth Engine v2.1 (A/B Test Branch)

## 📌 Обзор и отличия от версии v2.0

Версия **v2.1** развернута в изолированной структуре `v2_1/` для параллельного независимого A/B тестирования на одном VPS сервере:
- **v2.0 (Контрольная группа)**: работает на порту `8080`, служба `bybit-bot.service`.
- **v2.1 (Экспериментальная группа)**: работает на порту `8081`, служба `bybit-bot-v21.service`.

Обе версии работают полностью независимо, обращаются к Bybit V5 API только в режиме чтения, и ведут собственные независимые журналы и файлы персистентного состояния.

---

## 🚀 Ключевые улучшения в v2.1

### 1. Фильтр тренда BTC (BTC Delta Trend Filter)
- **Суть проблемы в v2.0**: во время падений рынка лонговые сигналы по альтам иногда срабатывали в противоход дампу BTC, что приводило к стоп-лоссам.
- **Решение в v2.1**: сделки Long по альткоинам открываются **только** если тренд BTC является бычьим (`EMA 20 > EMA 55` и цена выше границы канала). Сделки Short по альтам требуют подтверждения медвежьего давления BTC.
- Сам `BTCUSDT` оценивается по собственным сигналам без блокировки.

### 2. Кулдаун повторного входа (Re-entry Cooldown = 3 свечи / 3 часа)
- **Суть проблемы в v2.0**: после закрытия импульсной сделки по стопу или тейку бот мог мгновенно открыть повторный ордер на той же монете на излёте движения.
- **Решение в v2.1**: после закрытия позиции налагается аппаратный тайм-аут на **3 часовых бара (3 часа)** на данный инструмент в этом направлении.

### 3. Реальный учет комиссий Bybit с учетом MNT (0.09% Taker)
- Тарифный уровень Bybit: **Обычный пользователь** (Non-VIP).
- Базовая ставка тейкера: `0.10%`.
- Скидка при оплате комиссий в MNT: **-10%**.
- **Эффективная ставка тейкера в v2.1**: `0.09%` (`0.0009`), slippage `0.02%` (`0.0002`).

## 🛠 Управление службой v2.1 на VPS

```bash
# Запуск / Перезапуск службы
systemctl restart bybit-bot-v21

# Проверка статуса
systemctl status bybit-bot-v21

# Просмотр живых логов в реальном времени
journalctl -u bybit-bot-v21 -f

# Сброс статистики v2.1 и чистый рестарт ($300.00)
```
