## 1. Резюме интеграции

По вашему указанию модуль **News Core v1.1** (разработанный в диалоге `d447a1a3-8ddd-4230-9c57-bdef531c560f`) полностью упакован и интегрирован в архитектуру бота **v2.1** строго как **защитный щит (`NewsConfig.defensive_only()`)**.

### Ключевые ограничения и правила:
1. **Наступательные входы отключены**:
   - `enable_n1_pullback = False` (никаких отложек на откат свечи);
   - `enable_n3_crash_short = False` (никаких коротких шортов по крах-новостям);
   - `enable_n2_sympathy = False` (экосистемные сделки выключены).
2. **Все защитные щиты активны**:
   - 🛡️ **Regime Guard**: глобальный макро-блэкаут (запрет открытия новых сделок за $\pm 15$ минут вокруг FOMC, CPI, NFP) и контроль депега стейблкоинов ($>0.8\%$ отклонение USDC/USDT от \$1.00);
   - 🛡️ **Emergency Eject**: мгновенный рыночный сброс Long-позиций при подтверждённом шоке (`CRASH_SHOCK` -3: эксплойты, хаки, делистинги);
   - 🛡️ **Squeeze Escape**: мгновенное закрытие Short-позиций при мощном катализаторе (`MAJOR_CATALYST` +3: листинги Binance/Upbit, одобрение ETF);
   - 🛡️ **Runner Protection**: если позиция уже в плюсе $\ge 1.5R$, робот **никогда не сбрасывает её по рынку** на новостном шуме, а аккуратно подтягивает трейлинг-стоп до $+0.5R$, защищая накопленную прибыль;
   - 🛡️ **Soft Defense**: новостные заголовки от Tier-3 СМИ/Twitter без реального обвала цены ($\ge 1.0\%$) не выбивают позицию, а лишь подтягивают стоп;
   - 🛡️ **Super-Runner Defense**: при прибыли $\ge 0.8R$ и позитивном катализаторе стоп подтягивается в безубыток $+0.3\%$.

   В метод `process_bar_event` добавлен параметр `blocked_symbols` (проверка эмбарго перед открытием), а также методы `update_position_stop(sym, stop, reason)` и `emergency_close_position(sym, price, ts, reason)`.

   Автономный пакет с моделями, классификатором, подтверждением, матрицей позиций, источниками и тестами.
6. `v2_1/tests/test_v21_news_defense.py`:
   Комплексный набор из 9 тестов защитного профиля.

## 4. REST API для внешних новостных триггеров

Для взаимодействия с внешними парсерами новостей (например, Telegram-боты, RSS, CryptoPanic) на порту `8081` реализован эндпоинт:

```http
POST /api/news_event
Content-Type: application/json

{
  "headline": "SOLANA VALIDATOR EXPLOIT: Hackers drain funds",
  "symbol": "SOLUSDT",
  "source_tier": 1,
  "ret_1m": -0.015,
  "vol_1m": 5000.0,
  "vol_median_60m": 1000.0
}
```

**Ответ бота:**
```json
{
  "status": "ok",
  "actions_count": 1,
  "actions": [
    {
      "action_type": "CLOSE_MARKET",
      "symbol": "SOLUSDT",
      "side": "SHORT",
      "reason": "EMERGENCY_EJECT: CRASH_SHOCK confirmed (tier=1, ret=-1.5%)",
      "stop_price": null
    }
  ]
}
```
