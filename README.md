# Bybit Quantitative Research & Trading System (Beta v0.1)

Система количественного исследования и автоматизации торговли бессрочными USDT-контрактами Bybit (BTCUSDT, ETHUSDT) в строгом соответствии с Техническим заданием: `SPEC_RU.md`.

## 1. Архитектура системы

- **`src/config.py`**: Конфигурация, константы, временные рамки (UTC), параметры инструментов и торговые правила.
- **`src/bybit_client.py`**: Официальный клиент Bybit V5 (REST API) с поддержкой экспоненциального бэкоффа, валидацией `retCode` и обработкой временных сбоев.
- **`src/data_downloader.py`**: Загрузчик исторических данных (1m klines, история ставок funding, спецификации контрактов). Сохраняет неизменяемые сжатые JSON с SHA-256 хэшами, ведет журнал в SQLite (`data/metadata.db`) и формирует нормализованные таблицы Parquet (`data/parquet/`).
- **`src/data_auditor.py`**: Аудитор качества данных: проверка непрерывности минутной сетки, валидность OHLC, неотрицательность объемов и сверка агрегаций 1h/4h с биржевым API.
- **`src/indicators.py`**: Математически выверенные индикаторы без заглядывания вперед: 4h EMA(200) со сглаживанием 2/201 и начальным SMA(200), каналы пробоя Donchian (48, 96, 20 часов), Wilder ATR(14) с начальным SMA(14) True Range.
- **`src/strategy.py`**: Стратегия v0.1: закрытые свечи, фильтр тренда 4ч, пробой 1ч канала, выход по каналу (20ч) / тайм-ауту (120ч), скользящий стоп (trailing stop без ретроактивности) и разрешение портфельных конфликтов по нормализованной дистанции пробоя.
- **`src/risk_manager.py`**: Модуль управления капиталом на Decimal: базовый риск 1% equity, динамическое снижение до 0.5% при просадке ≥ 15% и восстановление при < 10%, ограничение номинала 2x equity, резервирование 120ч funding, округление вниз по `qtyStep`, фильтрация `minOrderQty` и `minNotionalValue`, дневной стоп 3% UTC, недельный стоп 7% UTC, аварийная остановка при просадке 30% от пикового equity.
- **`src/simulator.py`**: Хронологический событийный симулятор 1-минутных баров с учетом комиссий taker (0.06%), проскальзывания (0.02%), расписания funding, внутриминутных стопов (гэп по open vs касание) и маржинальных требований.
- **`src/order_fsm.py`**: Конечный автомат состояний ордеров (FSM) с уникальными клиентскими идентификаторами и reduce-only выходами.
- **`src/research_protocol.py`**: Оркестратор 3-этапного исследовательского протокола (Разработка 1 год -> Валидация 6 мес -> Финальный тест 6 мес), скользящих 30-дневных окон, стресс-тестов, бенчмарков и блочного бутстрапа.
- **`src/reporter.py`**: Генератор всеобъемлющего отчета в формате Markdown (`reports/RESEARCH_REPORT.md`) и CSV журналов сделок.
- **`src/paper_trader.py`**: Движок симуляции текущего рынка (paper trading).

## 2. Команды запуска

```bash
# 1. Загрузка всех исторических данных с Bybit
python main.py download --workers 6

# 2. Аудит качества загруженных данных
python main.py audit

# 3. Полный запуск двухлетнего исследовательского протокола и генерация отчёта
python main.py research

# 4. Запуск юнит-тестов
python -m pytest -v
```

## 3. Соблюдение ключевых требований ТЗ

- **Строгое отсутствие заглядывания вперед (Lookahead Bias)**: Сигналы генерируются исключительно на закрытии свечи $t$; исполнение моделируется по цене Open минуты $t+1$ с неблагоприятным смещением (slippage).
- **Бухгалтерия в Decimal**: Все расчеты размера позиции, номинала, комиссий и PnL производятся в фиксированной точности `Decimal`.
- **Без доливов и мартингейла**: Объем позиции строго ограничен риск-бюджетом; при недостаточности депозита для минимального лота 0.001 BTC сделка пропускается без округления вверх.
- **Учет funding**: Платежи за финансирование списываются/начисляются в точные моменты начисления (каждые 8 часов) исходя из открытой позиции до обработки новых входов.
