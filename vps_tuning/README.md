# Модуль низколатентного тюнинга VPS сервера (HFT Network & OS Tuning)

Этот модуль содержит системные настройки ядра Linux, сетевого стека, планировщика CPU и скрипты предпусковой диагностики задержки (RTT) для развертывания высокочастотных скальперских ядер (`v3.7`) на сервере Bybit V5.

---

## Состав модуля

1. **`sysctl_lowlatency.conf`**:
   - `net.ipv4.tcp_low_latency = 1` — отключение алгоритма Нейгла.
   - `net.ipv4.tcp_slow_start_after_idle = 0` — запрет сброса окна TCP после простоя (устраняет задержку при первом ордере после паузы).
   - Расширение сетевых очередей (`netdev_max_backlog = 30000`, `somaxconn = 4096`) и буферов сокетов (до 16 МБ).
   - Быстрая утилизация соединений `TIME_WAIT` (`tcp_tw_reuse = 1`).

2. **`tune_vps.sh`**:
   - Скрипт автоматического применения параметров `sysctl`.
   - Перевод ядер CPU в режим максимальной производительности (`performance governor`), блокирующий засыпание в C-states.
   - Установка системных лимитов на файловые дескрипторы (`nofile = 65535`).
   - Автоматический запуск теста пинга и джиттера.

3. **`preflight_check.py`**:
   - Асинхронный замер RTT по 50 пакетам WebSocket Ping/Pong к `stream.bybit.com`.
   - Расчет медианы (p50), 95-го и 99-го перцентилей, а также стандартного отклонения (Jitter).
   - Проверка фактических ставок комиссий аккаунта (проверка применения скидки 10% с MNT).

4. **`bybit-scalper.service`**:
   - Systemd юнит с шедулером реального времени `fifo` (`CPUSchedulingPolicy=fifo`, `CPUSchedulingPriority=50`).
   - Приоритет `Nice=-15`.

---

## Быстрый запуск на VPS сервере

Подключитесь к вашему VPS серверу (`150.241.98.70`) и выполните:

```bash
cd /opt/bybit-bot/vps_tuning
sudo bash tune_vps.sh
```

Для повторной проверки пинга в любое время:
```bash
python3 preflight_check.py
```
